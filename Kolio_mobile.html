Kolio Prise de notes de réunion
Comment ça marche ?
1. Prenez vos notes ici pendant la réunion (tout est enregistré automatiquement sur ce téléphone).
2. Appuyez sur Partager pour vous envoyer le fichier .json par mail.
3. Sur l'ordinateur : téléchargez la pièce jointe, puis dans Kolio → Organisation quotidienne → Réunions → 📥 Importer une réunion.
